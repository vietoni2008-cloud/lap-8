# Portfolio CV cá nhân
## Sản phẩm này là gì?
Website giới thiệu bản thân, kỹ năng lập trình và các dự án học tập ngành CNTT của sinh viên Nguyễn Đức Việt.
## Demo
https://github.io
## Tính năng
- Xem thông tin cá nhân và định hướng học tập.
- Xem danh sách dự án C++ và Web.
- Gửi lời nhắn liên hệ trực tiếp qua Form HTML5.
## Cách mở
1. Truy cập vào đường link ở mục Demo phía trên.
2. Sử dụng menu điều hướng để di chuyển nhanh đến các phần mong muốn.
